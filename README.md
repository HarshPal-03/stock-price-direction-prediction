# stock-price-direction-prediction
## Overview
This project predicts stock price direction using Machine Learning and Deep Learning models.

## Technologies
- Python
- Pandas
- NumPy
- TensorFlow
- Scikit-learn
- Matplotlib
- Seaborn

## Models Used
- LSTM
- Neural Network
- Logistic Regression

## Results
- LSTM Accuracy: 53.62%
- Neural Network Accuracy: 53.62%
- Logistic Regression Accuracy: 49.48%

## Features
- Data preprocessing
- Technical indicators (SMA, EMA, Returns)
- Model comparison
- Confusion matrix
- Data visualization
